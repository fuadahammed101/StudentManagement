# 🎓 Student Management System (Bash)

A simple terminal-based Student Management System built using **Bash scripting**. It allows you to **insert**, **search**, **update**, **delete**, and **display** student records using arrays and basic shell operations.

---

## 📋 Features

* Insert multiple students' data
* Display all records
* Search by student ID
* Update student information
* Delete a student record
* Validates unique student IDs

---

## 🛠️ Technologies Used

* Bash (Shell Scripting)
* Unix/Linux terminal

---

## 🚀 Getting Started

### Requirements

* Linux or macOS terminal with `bash` shell
* No external dependencies

### Run the Script

```bash
chmod +x student_management.sh
./student_management.sh
```
